# 证据驱动决策与交付

统一目标：让 Mio 依据当前证据修正准备计划，保留有效成果，并交付有来源、有取舍、有下一步操作的结果。

实现分为三个阶段。第一阶段完善文档融合排序、精确引用、可暂停恢复的后台索引和受限网页正文读取。第二阶段把当前计划、步骤成果、失败和资源状态加入规划上下文，生成局部变更建议，明确保留、修改、删除及受影响步骤；增加带硬条件和权重的多指标比较。第三阶段把证据、缺口和下一步操作组织成交付报告，减少当前计划查询对全部任务历史的依赖，并统一页面轮询。

计划建议始终是未采纳数据，用户确认后才改变执行范围；准备计划不能批准外部业务写入。未知操作不通过重规划重放。引用核对证明片段与版本一致，不证明片段中的观点正确。网页正文来自显式配置的 HTTPS 域名，作为不可信资料处理。后台索引只在用户显式启动后消费知识预算，文档或模型版本改变后旧结果不发布。

每阶段提交可用功能和必要回归；测试使用隔离数据库和本地响应，不联系真实业务或付费模型。
