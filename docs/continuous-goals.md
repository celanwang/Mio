# 持续目标执行

统一目标：在明确范围、预算与期限内持续推进用户目标，支持局部修订、事件唤醒、可信业务状态跟踪、并行准备和能力扩展。沿用现有目标、任务、权限、预算与 PostgreSQL，不引入新的流程框架。

| 阶段 | 功能交付 |
| --- | --- |
| 1 | 结构化字段、版本化步骤、局部修订、计划建议和页面管理 |
| 2 | 持久唤醒、定时推进、有限执行额度、暂停及重启恢复 |
| 3 | 已核实业务资源与追加状态观测、履约视图 |
| 4 | 独立准备步骤的有界并行、方案字段比较 |
| 5 | 信息检索与文档助手、文档导入和交付物保存 |
| 6 | 配置驱动的能力包、准备型远程 Agent 适配 |

后台只执行用户确认的 PREPARE 步骤。写入继续走前台已有权限和批准。准备任务的完成、业务资源的创建、履约状态和目标条件分别展示。每阶段验证关键行为，最后运行一次现有完整离线入口；不以测试数量代替功能。
