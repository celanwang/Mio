# 领域证据契约

此目录由开发者维护，运行时仅在启动时读取，不接受模型、网页或 HTTP 接口安装配置。默认示例全部关闭。示例字段不是麦当劳或微博实际返回格式，不能直接启用；需根据当前注册工具和脱敏真实回执确认路径、成功条件、数值单位及编号类型后版本化提交。

每个配置绑定一个 capabilityId 与精确 tool。READ 配置声明输出契约 id、事实 key/type、5至300秒的本地有效窗口、字段路径/类型/单位及会使原事实失效的工具。条件使用 JSON Pointer 对非空 JSON 标量做严格相等检查，数字字符串不转换为数值，币种和单位须列入条件。有效窗口是本地使用约定，不宣称供应商保证报价有效。原格式无法验证时不产生事实。

WRITE 配置会收紧领域工具为写操作，即使供应商元数据误标只读也不能在准备任务执行；不把 READ 配置用作权限放行。WRITE 仅核验成功条件及确切字符串资源编号，证明创建，不证明支付、送达或发布后的外部状态；失败、未知、重复键、多个 JSON 文档或不匹配的数据保持 UNKNOWN。供应商核查适配器未实现时仍需人工核查，禁止自动重发。不能覆盖内置腾讯出行适配器。

新增 READ 契约会出现在能力发现及多条件比较中；WRITE 为该能力增加 resource-reference 输出契约。能力版本包含配置指纹，修改后旧输出与批准不按新契约重新解释。未知能力、重复工具或契约冲突会阻止启动。诊断接口列出已加载适配器，不探测供应商。

扩展能力包也可按 capabilityId 使用这些契约，但远程报告不会因为文字声称成功而获得业务事实。需要实际响应满足受信配置且来自对应工具调用。契约文件属于离线源码指纹范围。
